# Contributing Guidelines

First off, thank you for considering contributing to the Azure AI Engineer Roadmap! It's people like you that make this an awesome resource for everyone.

## How Can I Contribute?

### 1. Suggesting Learning Resources
If you find a fantastic free tutorial, YouTube video, or Microsoft Learn module that isn't listed in our module curriculum (e.g., `01-python/README.md`), you can submit a Pull Request to add it.

### 2. Adding Practice Exercises
We want this roadmap to be highly practical. If you have a great idea for a small project or practice exercise for any of the modules, please submit it!

### 3. Fixing Typos
If you spot a typo or a broken link, feel free to fix it and open a PR.

## Submitting a Pull Request (PR)
1. Fork the repository
2. Create your feature branch (`git checkout -b feature/AmazingResource`)
3. Commit your changes (`git commit -m 'Add some AmazingResource'`)
4. Push to the branch (`git push origin feature/AmazingResource`)
5. Open a Pull Request

## Ground Rules
- Ensure any added learning resources are **free** or have a robust free tier. We want this roadmap to be accessible to everyone.
- Keep the tone encouraging and professional.
