# 🗺️ Azure AI Engineer Roadmap

A comprehensive, open-source roadmap and curriculum for becoming a Microsoft Azure AI Engineer. 

This repository serves as both a **study guide for aspirants** and a **portfolio of proof**. It contains a step-by-step curriculum to learn Python, master Azure AI services, prepare for the AI-102 certification, and build a Generative AI portfolio.

## 🌟 How to Use This Repository (For Aspirants)

If you want to use this roadmap for your own learning journey:
1. **Fork this repository** to your own GitHub account.
2. Clone your forked repo locally.
3. Check out the [Master Roadmap](progress/roadmap.md) to see the phases.
4. Go into each module folder (like `01-python/`) to find the learning resources and assignments.
5. Record your progress by checking the boxes and tracking your own journey in your cloned repository!
