# Phase 2: Azure AI Services & SDKs

Welcome to Phase 2! Now that you have mastered advanced Python concepts, we are ready to dive into the core of the Azure AI-102 certification.

## Objectives
1. Understand the landscape of Azure Cognitive Services (Vision, Language, Speech, Search).
2. Provision Azure AI resources (specifically Azure OpenAI) in the Azure Portal.
3. Learn how to authenticate securely using API Keys and `DefaultAzureCredential`.
4. Make your first API calls to Azure OpenAI using the official Python SDK.

## Prerequisites
Before we write code for this phase, you must have:
- An active Microsoft Azure account.
- Access to Azure OpenAI (this may require filling out an access request form on Azure, depending on current policies).
- The Azure CLI installed on your computer (for authentication).
